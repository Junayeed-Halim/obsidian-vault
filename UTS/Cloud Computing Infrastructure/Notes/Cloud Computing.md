# Cloud Computing

Course notes for [[Cloud Computing]].

## Overview

Covers cloud architecture, service models (IaaS, PaaS, SaaS), deployment models (public, private, hybrid), and major platforms.

### Core Topics
- **Service Models:** IaaS (EC2, VMs), PaaS (App Service, Lambda), SaaS (Office 365, Salesforce).
- **Deployment Models:** Public cloud, private cloud, hybrid cloud, multi-cloud.
- **Virtualisation:** Hypervisors, containers (Docker, Kubernetes).
- **Storage:** Object storage (S3, Blob), block storage (EBS, Disk), file storage (EFS, Files).
- **Networking:** VPC/VNet, load balancers, CDNs, DNS.
- **Security:** IAM, encryption, firewalls, compliance.
- **Serverless:** Lambda, Azure Functions — event-driven, pay-per-use.
- **Cost Management:** Pricing models, cost optimisation, reserved vs on-demand vs spot.

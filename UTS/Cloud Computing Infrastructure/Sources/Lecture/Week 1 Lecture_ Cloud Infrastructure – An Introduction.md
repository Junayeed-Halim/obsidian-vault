**Overview:**

At the end of this module, you should be able to answer these questions:

- What is could? What is cloud computing?
- What are the difference between classical computing and cloud computing?
- What is the cost model of cloud computing?
- You should know about the cloud service model and cloud deployment models.
- You should know about IaaS cloud Architecture and explain the difference between computer O.S. and cloud O.S.

**Summary:**

In this module, we have learnt about the basic concepts (e.g. cost model, service model, deployment model) of cloud computing and understand the difference between cloud computing and classical computing.

Make sure you understand:

Cloud and cloud computing

- The cost model of cloud computing
- Cloud service model
- Cloud deployment models

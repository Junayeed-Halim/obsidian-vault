Welcome to 42891/41891: Infrastructure for Cloud Computing/Cloud Computing Infrastructure.

This subject introduces the concepts and implementation of cloud computing infrastructure, and complements the existing cloud computing subjects. Topics such as cloud architecture, virtualisation and storage technologies, and data centre fundamentals, as well as security and compliance in the cloud, are explored. This subject is heavily influenced by industry interaction, and includes hands-on labs and workshops using and comparing commonly found tools within the cloud infrastructure industry.

The following are important notes that you need to consider carefully when deciding to move ahead to do the subject. When using the FEIT computer lab for this subject, students should bring their own USB external hard disks with at least 64GB free to run/save their work. A USB 3.0 SSD (solid state drive) is recommended. For students working on their own hardware off campus, to run the VMware virtual machines used in this subject it is recommended to have a machine with **32GB** of RAM and at least 40GB of disk space. Students must also be able to run VMware virtual machines using VMware Workstation Player (Windows/Linux) or VMware Fusion (MacOS).

I wish you all successful and enjoy the subject.

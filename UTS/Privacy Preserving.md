# Privacy Preserving Technologies

Course notes for [[UTS/Privacy Preserving]].

## Overview

Privacy-preserving technologies aim to protect personal data while enabling useful computation and analysis. Key areas:

### Core Topics
- **Differential Privacy** — adding noise to protect individual records while preserving aggregate statistics.
- **Secure Multi-Party Computation (MPC)** — multiple parties compute a function over their inputs without revealing them.
- **Homomorphic Encryption** — perform computations on encrypted data without decrypting.
- **Federated Learning** — train models across decentralised devices without sharing raw data.
- **k-Anonymity, l-Diversity, t-Closeness** — anonymisation techniques for databases.
- **Privacy Legislation** — GDPR, Australian Privacy Act, etc.

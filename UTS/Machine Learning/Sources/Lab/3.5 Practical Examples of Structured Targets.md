# Loss for Structured Output Spaces

In the previous sections, we studied instance loss functions for two fundamental cases: scalar regression (where \(\mathcal{Y} = \mathbb{R}\)) and classification (where \(\mathcal{Y}\) is a finite set of categories represented as probability distributions). In both cases, the output of the model is either a single number or a fixed-length vector, and the loss function is a straightforward function of the two.

In practice, however, many tasks demand output spaces that are far richer in structure. The output may be a geometric object (a bounding box), a spatial field (a segmentation mask), a sequence of symbols (a sentence), or even the solution to a differential equation across a continuous domain. In each of these cases, the designer of the learning system faces a non-trivial modelling question: *what does it mean for a prediction to be "close" to the ground truth, and how do we encode that notion into a computable, differentiable number?*

This section examines four representative cases in increasing order of structural complexity, drawing out the common design principles along the way.

**Note:** Due to the practical complexity of these cases, the discussion is at times technical and detailed. You can skip the details if you are not interested in the mathematical intricacies; we will discuss the core ideas at online sessions. If one set of tasks is of particular interest to you, I encourage you to read the details and start your course project from there. Also, the design choices discussed here depend not only on the loss functions, but also on the model architecture (what to output?) and sometimes the training algorithm. It is recommended to come back to this section after you have learned the later contents on model architectures and training algorithms.

## Case 1: Object Detection — Sets of Geometric Objects

The task.

In an object detection task, the model receives an image and must predict the locations and identities of all objects present. The training examples contain annotations in the form of a *set of bounding boxes*, each annotated with a class label. Formally, if there are \(K\) object categories, the annotation for an image with \(N\) objects can be represented as a set

\[ \mathcal{B}^* = \{(b_1^*, c_1^*),\, (b_2^*, c_2^*),\, \ldots,\, (b_N^*, c_N^*)\}, \]

where \(b_i^* \in \mathbb{R}^4\) encodes the ground-truth bounding box (e.g.\ as \((x_{\min}, y_{\min}, x_{\max}, y_{\max})\)) and \(c_i^* \in \{1, \ldots, K\}\) is the ground-truth class.

Detecting objects in an image. The ground truth contains two objects (cats); for each object, the model must predict its bounding box and class label.

What makes this hard?

One fundamental difficulty is that \(\mathcal{B}^*\) is a *set* — an unordered collection of variable size. If the model predicts \(M\) boxes \(\hat{\mathcal{B}} = \{(\hat{b}_1, \hat{c}_1), \ldots, (\hat{b}_M, \hat{c}_M)\}\), there is no canonical way to "subtract" one set from another and produce a discrepancy measure between \(\hat{\mathcal{B}}\) and \(\mathcal{B}^*\).

One might be tempted to simply pair up predicted boxes and ground-truth boxes in order, compute the loss for each pair, and sum. But this fails immediately: the sets have no inherent ordering, and pairing the first predicted box with the first ground-truth box is arbitrary and potentially misleading.

A. The matching approach.

The standard resolution is to introduce an explicit *matching* (or *assignment*) step before computing the loss. The idea is to find a bijection between a subset of predicted boxes and the set of ground-truth boxes that is in some sense "optimal", and then compute the loss only for matched pairs, penalising unmatched predictions as false positives and unmatched ground-truth boxes as false negatives.

Two dominant strategies are widely used.

- **IoU-based thresholding.** A predicted box \(\hat{b}\) is matched to a ground-truth box \(b^*\) if their *Intersection over Union* (IoU) exceeds some threshold \(\tau\):
\[ \mathrm{IoU}(\hat{b}, b^*) = \frac{|\hat{b} \cap b^*|}{|\hat{b} \cup b^*|} \geq \tau. \]
This is simple and geometrically intuitive, but the threshold \(\tau\) is a hyperparameter and the assignment can be ambiguous when multiple predictions overlap with the same ground-truth box.
- **Hungarian algorithm.** Find the assignment \(\sigma\) of predictions to ground-truth boxes that minimises the total matching cost:
\[ \sigma^* = \arg\min_{\sigma} \sum_{j=1}^{N} c_{\mathrm{match}}(\hat{b}_{\sigma(j)},\, b_j^*), \]
where \(c_{\mathrm{match}}\) is some cost function (often a combination of IoU and class probability). This is the approach taken by modern architectures such as DETR. The Hungarian algorithm solves this assignment problem in polynomial time.

Once the matching is determined, the total loss decomposes into a sum over matched pairs, each contributing a *localisation loss* (how far the predicted box is from the ground truth) and a *classification loss* (error on the class prediction):

\[ L_{\mathrm{det}} = \sum_{j \in \mathrm{matched}} \underbrace{L_{\mathrm{cls}}(\hat{p}_{\sigma(j)},\, c_j^*)}_{\text{class prediction}} + \lambda \underbrace{L_{\mathrm{box}}(\hat{b}_{\sigma(j)},\, b_j^*)}_{\text{box localisation}} + \underbrace{\sum_{i \notin \mathrm{matched}} L_{\mathrm{bg}}(\hat{p}_i)}_{\text{false positive penalty}}, \]

where \(\hat{p}_i\) is the predicted class probability vector, \(\lambda > 0\) is a hyperparameter balancing the two objectives, and \(L_{\mathrm{bg}}\) penalises predicted boxes that were not matched to any ground truth (encouraging them to predict the "background" class).

For the box regression part, a common choice is the smooth \(\ell_1\) loss (Huber loss) applied to the box coordinates, or the *GIoU loss* which directly optimises a differentiable relaxation of the IoU metric.

B. The anchor-based approach (YOLO).

An alternative design philosophy avoids the matching step altogether by *pre-committing* the model's output format to a fixed spatial grid. This is the approach taken by the YOLO family of detectors (You Only Look Once).

The input image is divided into an \(S \times S\) grid of cells. Each cell is responsible for detecting objects whose centre falls within that cell. Each cell predicts \(B\) bounding boxes, and for each box it outputs: the box coordinates \((x, y, w, h)\) relative to the cell, an *objectness score* \(\hat{o} \in [0,1]\) indicating confidence that an object is present, and \(K\) class probabilities \((\hat{p}_1, \ldots, \hat{p}_K)\).

The assignment between predictions and ground-truth objects is now *deterministic and fixed by construction*: a ground-truth box with centre in cell \((i, j)\) is assigned to whichever of the \(B\) predictors in that cell has the highest IoU with it. No optimisation over assignments is needed. The total loss sums over all cells and all \(B\) predictors per cell:

\begin{align} L_{\mathrm{YOLO}} =\;& \lambda_{\mathrm{coord}} \sum_{i,b}^{\mathrm{obj}} \Bigl[(x_i - \hat{x}_{ib})^2 + (y_i - \hat{y}_{ib})^2 + (\sqrt{w_i} - \sqrt{\hat{w}_{ib}})^2 + (\sqrt{h_i} - \sqrt{\hat{h}_{ib}})^2\Bigr] \nonumber\\ +\;&\sum_{i,b}^{\mathrm{obj}} (1 - \hat{o}_{ib})^2 + \lambda_{\mathrm{noobj}} \sum_{i,b}^{\mathrm{noobj}} \hat{o}_{ib}^2 \nonumber\\ +\;&\sum_{i}^{\mathrm{obj}} \sum_{k=1}^{K} (p_{ik} - \hat{p}_{ik})^2, \end{align}

where the superscripts "obj" and "noobj" restrict the sum to predictor–cell pairs that are, or are not, responsible for a ground-truth object.

Two design choices in this formula are worth remarking on.

- **Square root on \(w\) and \(h\).** A deviation of 10 pixels on a box of width 20 pixels is a much larger relative error than the same deviation on a box of width 200 pixels. Taking square roots compresses the scale of large boxes and expands the scale of small ones, partially correcting for this imbalance.
- **Asymmetric objectness weighting.** \(\lambda_{\mathrm{noobj}} \ll 1\) (typically 0.5), while \(\lambda_{\mathrm{coord}}\) is large (typically 5). In a typical image, the vast majority of the \(S \times S \times B\) predictors cover no object. Without this asymmetry, the gradient would be overwhelmingly dominated by the "background" signal, swamping the localisation learning.

Matching vs. anchor-based: a comparison.

- **Matching-based methods** (e.g. DETR) make no prior assumptions about where objects can appear or how many there are. The matching is solved globally and optimally at each training step, but this comes at the cost of a computationally expensive assignment step and typically slower convergence.
- **Anchor-based methods** (e.g. YOLO) hard-code the assignment into the output structure. This makes training much simpler and faster, but introduces inductive biases: the grid resolution \(S\) limits how close two objects can be before their centres fall in the same cell, and the number of predictors \(B\) per cell limits how many objects can be detected per region. For small and densely packed objects, this can be a significant limitation.

Both families continue to be actively developed, and many modern detectors combine ideas from both (e.g. using anchor-free prediction heads with IoU-based label assignment).

## Case 2: Image Segmentation — Spatial Structure in the Output

The task.

In semantic segmentation, the model must assign a class label to every pixel of the input image. If the image has \(H \times W\) pixels and there are \(K\) classes, the prediction is a tensor \(\hat{Y} \in \mathbb{R}^{H \times W \times K}\), where \(\hat{Y}_{h,w,:}\) is a probability distribution over classes for pixel \((h, w)\). The ground truth is a label map \(Y^* \in \{1, \ldots, K\}^{H \times W}\).

Semantic segmentation. The model must predict a class label for every pixel; the loss measures the discrepancy between the predicted mask and the ground truth.

The naive approach: pixel-wise cross-entropy.

The simplest loss is to treat each pixel as an independent classification problem and average the cross-entropy losses:

\[ L_{\mathrm{seg}} = \frac{1}{HW} \sum_{h=1}^{H} \sum_{w=1}^{W} L_{\mathrm{CE}}\!\left(\hat{Y}_{h,w,:},\; Y^*_{h,w}\right). \]

This is the direct analogue of scalar classification loss, and it works surprisingly well in practice. The key insight that justifies it is: although pixels are spatially correlated, the loss function need not model this correlation explicitly. The model *architecture* (e.g. convolutional layers) is responsible for learning spatial structure, while the loss only needs to provide a correct training signal at each position independently.

When pixel-wise loss is insufficient: class imbalance.

A common failure mode arises when the object of interest occupies only a small fraction of the image. Consider medical image segmentation where a tumour covers 2% of the pixels. A model that classifies every pixel as "background" would achieve 98% pixel accuracy, yet be completely useless for the clinical task of finding the tumour.

This motivates the *Dice loss*, which directly measures the overlap between the predicted segmentation mask and the ground truth, and is robust to class imbalance:

\[ L_{\mathrm{Dice}} = 1 - \frac{2 \sum_{h,w} \hat{p}_{h,w} \cdot \mathbf{1}[Y^*_{h,w} = 1]} {\sum_{h,w} \hat{p}_{h,w} + \sum_{h,w} \mathbf{1}[Y^*_{h,w} = 1]}, \]

where \(\hat{p}_{h,w}\) is the predicted probability of the foreground class at pixel \((h, w)\). The Dice loss equals zero when prediction and ground truth overlap perfectly, and one when they are entirely disjoint. In practice, a combination of cross-entropy and Dice loss is often used.

Dice was originally proposed as a metric for evaluating segmentation quality *after* the model is trained, not for optimisation. The loss formulation above is designed so that optimisation is directly on the evaluation metric — a common design pattern when the final task metric is differentiable. A good example is medical image segmentation ([Springer, 2022](https://link.springer.com/article/10.1007/s10278-022-00735-3)).

See the demo notebook [demo3_5_img_seg.ipynb](https://canvas.uts.edu.au/courses/42500/files/12975043?verifier=JMDY13HPgfTuZYZkz5suDV32wnVpeo2KShIGXtb9&wrap=1) for a concrete example comparing BCE loss and Dice loss on a segmentation task with class imbalance.

Incorporating spatial continuity: structured losses.

Both losses above are "pixel-exchangeable": swapping the predictions of two pixels changes the numerical value of the loss, but the loss does not *explicitly* penalise spatial incoherence. In some applications, one may wish to penalise predictions that are spatially fragmented even if every individual pixel is classified correctly.

This can be achieved by adding a *regularisation term* that measures spatial discontinuity, for example based on a *total variation* penalty:

\[ L = L_{\mathrm{seg}} + \mu \sum_{(h,w) \sim (h',w')} \|\hat{Y}_{h,w,:} - \hat{Y}_{h',w',:}\|^2, \]

where the sum is over neighbouring pixel pairs. The hyperparameter \(\mu\) controls the trade-off between fitting individual pixels and ensuring spatial smoothness. The design of this regularisation term is itself a modelling choice that encodes domain knowledge about the expected structure of the output.

## Case 3: Language Modelling — Discrete Sequences and Scalability

The task.

In a language model, the output is a sequence of tokens \(y = (y_1, y_2, \ldots, y_T)\) drawn from a vocabulary \(\mathcal{V}\) of size \(|\mathcal{V}|\). For the largest modern models, \(|\mathcal{V}|\) is on the order of \(10^5\) tokens.

The theoretical ideal: sequence-level loss.

In principle, we would like to compare the model's joint distribution over entire sequences with the true distribution:

\[ L_{\mathrm{seq}} = D_{\mathrm{KL}}\!\left(P_{\mathrm{data}}(y_{1:T}) \,\Big\|\, Q_\theta(y_{1:T})\right). \]

However, the number of possible sequences of length \(T\) is \(|\mathcal{V}|^T\), which is astronomically large. Computing or even sampling from this distribution is entirely intractable.

The autoregressive factorisation.

The key that makes language modelling tractable is the *chain rule of probability*, which allows us to decompose the joint distribution over a sequence into a product of conditional distributions:

\[ P(y_{1:T}) = P(y_1) \cdot P(y_2 \mid y_1) \cdot P(y_3 \mid y_1, y_2) \cdots = \prod_{t=1}^{T} P(y_t \mid y_{1:t-1}). \]

This is not an approximation: it is an exact identity. A model that correctly learns each conditional \(P(y_t \mid y_{1:t-1})\) also correctly learns the joint distribution over sequences.

Training with *teacher forcing* then reduces to a single classification problem at each step: given the true prefix \(y_{1:t-1}\), predict the next token \(y_t\). The total loss is the average of per-step cross-entropy losses:

\[ L_{\mathrm{LM}} = -\frac{1}{T} \sum_{t=1}^{T} \log Q_\theta(y_t \mid y_{1:t-1}). \]

This is computationally very efficient: the model processes the entire sequence in a single forward pass (using a causal mask to prevent positions from attending to future tokens), and the loss at all \(T\) positions is computed simultaneously.

In reality, the input tokens are not single characters but word pieces, and the vocabulary size is much larger than 26. Hence in the last layer there can be computational challenges in computing the softmax and the corresponding loss/gradient. The standard implementation in modern frameworks (e.g. PyTorch's CrossEntropyLoss) is optimised to handle this efficiently.

The vocabulary size challenge.

Even within a single step, predicting the next token out of \(|\mathcal{V}| \approx 10^5\) symbols is a large-scale classification problem. The final layer must compute a distribution over all \(|\mathcal{V}|\) tokens, involving a matrix multiplication of size \(d_{\mathrm{model}} \times |\mathcal{V}|\). Several practical techniques address the cost:

- **Tied embeddings.** Share the weight matrix of the output projection with the input token embedding matrix, halving the parameter count of this layer.
- **Mixed-precision softmax.** Compute the softmax in lower precision (e.g. float16) to reduce memory bandwidth demands.
- **Hierarchical / adaptive softmax.** Organise the vocabulary into a two-level hierarchy (common tokens at the top level, rare tokens at lower levels), reducing the average computation per prediction from \(O(|\mathcal{V}|)\) to \(O(\log |\mathcal{V}|)\) at the cost of some implementation complexity.

The gap between training loss and evaluation metrics.

An important subtlety is the mismatch between the training objective and the metrics used to evaluate system quality. The cross-entropy loss (equivalently, *perplexity*) measures only the model's ability to predict the next token given the *true* preceding context. Downstream metrics such as BLEU (translation), ROUGE (summarisation), or human preference ratings measure something qualitatively different: the quality of sequences *generated* by the model, where the preceding context was produced by the model itself rather than the ground truth.

This discrepancy is known as *exposure bias* and is an active area of research in sequence modelling.

## Case 4: Physics-Informed Neural Networks — Loss Encoding Domain Knowledge

The task.

We end with a case that departs most radically from the standard supervised learning setup. In *Physics-Informed Neural Networks* (PINNs) [Raissi et al., 2019], the goal is to solve a partial differential equation (PDE) by training a neural network to satisfy it. The model maps spatial and temporal coordinates to physical field values, e.g. \(f_\theta: (x, t) \mapsto u\) for a scalar field \(u\) defined over a spatial domain \(\Omega \subset \mathbb{R}^d\) and time interval \([0, T]\).

The PDE, together with its initial conditions (ICs) and boundary conditions (BCs), constitutes the full specification of the problem:

\begin{align*} \mathcal{N}[u](x, t) &= 0, \quad (x, t) \in \Omega \times (0, T], &\text{(PDE)}\\ u(x, 0) &= u_0(x), \quad x \in \Omega, &\text{(initial condition)}\\ \mathcal{B}[u](x, t) &= g(x, t), \quad (x, t) \in \partial\Omega \times [0, T], &\text{(boundary condition)} \end{align*}

where \(\mathcal{N}\) is a (possibly nonlinear) differential operator and \(\mathcal{B}\) is a boundary operator.

Loss without labelled data.

In the PINN setting, there is generically no dataset of \((x, u)\) pairs to supervise the model. Instead, the training signal comes entirely from the residuals of the equations above. The loss is a sum of three terms:

\[ L_{\mathrm{PINN}} = \underbrace{\frac{1}{|\mathcal{T}_r|} \sum_{(x,t) \in \mathcal{T}_r} \left|\mathcal{N}[f_\theta](x, t)\right|^2}_{L_{\mathrm{PDE}}:\ \text{equation residual}} + \underbrace{\frac{1}{|\mathcal{T}_0|} \sum_{x \in \mathcal{T}_0} \left|f_\theta(x, 0) - u_0(x)\right|^2}_{L_{\mathrm{IC}}:\ \text{initial condition}} + \underbrace{\frac{1}{|\mathcal{T}_b|} \sum_{(x,t) \in \mathcal{T}_b} \left|\mathcal{B}[f_\theta](x, t) - g(x, t)\right|^2}_{L_{\mathrm{BC}}:\ \text{boundary condition}}, \]

where \(\mathcal{T}_r\), \(\mathcal{T}_0\), \(\mathcal{T}_b\) are collocation point sets sampled from the interior, the initial time slice, and the boundary, respectively. The spatial and temporal derivatives in \(\mathcal{N}[f_\theta]\) are computed via *automatic differentiation* of the network, so the entire loss is differentiable with respect to \(\theta\).

The heterogeneous nature of the three components.

This is a crucial point that distinguishes PINNs from standard supervised learning: the three components of the loss are *not* measuring the same kind of error.

- \(L_{\mathrm{IC}}\) and \(L_{\mathrm{BC}}\) measure violations of **hard constraints**: the solution must satisfy specific prescribed values at specific locations. The desired value of each of these terms is exactly zero, and deviations are unambiguously "wrong". These terms are analogous to the supervised loss we saw in regression.
- \(L_{\mathrm{PDE}}\) measures the residual of the governing equation at interior collocation points. This term is more subtle: unlike IC/BC losses, it does not compare the model's output against a provided target value. Instead, it evaluates a functional of the model's output (involving its partial derivatives), which must be identically zero for the true solution. The magnitude of this residual depends on both the normalisation of the PDE and the characteristic scales of the solution, making it inherently difficult to compare to the IC/BC terms in absolute terms.

In practice, the three terms are combined with scalar weights \((\lambda_r, \lambda_0, \lambda_b)\):

\[ L = \lambda_r L_{\mathrm{PDE}} + \lambda_0 L_{\mathrm{IC}} + \lambda_b L_{\mathrm{BC}}. \]

Choosing these weights well is critical and non-trivial. Setting them uniformly to 1 can lead to one term dominating and the others being ignored during training, producing a model that satisfies the boundary conditions but poorly solves the PDE.

This weight-balancing problem is an active area of research. Methods such as adaptive loss weighting [Wang et al., 2021] monitor the relative magnitudes of the gradient norms of each loss term and adjust the weights dynamically during training to ensure they are all being optimised at comparable rates.

Key design lesson.

The PINN example illustrates the most extreme case of the principle seen throughout this section: when domain knowledge about the structure of the desired output is available, it can and should be encoded directly into the loss function. Here, the "labels" are not data points at all, but mathematical equations. The design of the loss function is inseparable from the formulation of the problem itself.

## Summary: Design Principles for Structured Output Losses

Looking across the four cases above, a few recurring design principles emerge.

- **Decompose and conquer.** When the output is complex, decompose the loss into simpler components that each measure a specific, well-understood type of error. Alignment between components (as in detection) and weighting between components (as in PINNs) are then the key design choices.
- **Separate discrete matching from differentiable optimisation.** Whenever the output is a set or requires an assignment (as in detection), the matching step should be solved exactly as a discrete optimisation problem. The gradient flows only through the differentiable loss, conditioned on a fixed matching.
- **Architecture and loss co-design.** The loss function and the model architecture are not independent choices. In segmentation, spatial structure is encoded in the architecture (convolutions) rather than the loss. In language modelling, the autoregressive factorisation defines both the model's computation and the form of the loss. The loss designer always implicitly makes assumptions about what the model will be able to learn.
- **Domain knowledge as loss components.** When external knowledge about the structure of the desired output is available — physical laws, geometric constraints, linguistic structure — it can be incorporated as additional terms in the loss function. This is the most direct route from domain expertise to improved learning.

## Summary of the Criterion (Ein vs Eout)

This week we discussed the loss as functional -- which takes in functions and output numbers.

The key ideas are

i) What is the curse of dimension -- individual samples occupy vanishing small volumes, so to fill up the input space (and represent how well/poor a hypothesis works) is infeasible. 

ii) Change of perspective: think of each hypothesis performing "coloring" of the input space, according to whether it produces correct/wrong answers everywhere.

iii) Evaluation as sampling of "colors". If one takes N samples from the space, and check their colors (ratio), the ratio will not be very different from the real one.

iv) See Quiz Question 3: the above argument applies to FIXED h. If the h is SELECTED (as we would do) from a range, the guarantee is still valid, but not so quantitatively effective.

Tutorials

The following tutorials show the realisation of using the back-propagation algorithm to train a neural network model.

## Define the neural network computational model

In this video, we implement the neural network computational model by introducing how the processing of data using multiple perceptions can be formulated as matrix multiplications. We then further process the data using another layer of perceptron(s), which makes a simple neural network architecture.

## Define loss function for a neural network classifier

In this video, we consider how to link the numerical outputs of a multi-layer perception (neural network) to the goal of a classification problem. The loss of function is defined by comparing the belief generated by the neural network and the class annotation.

## Compute the gradient of the loss function

To minimise the loss, the first step is to figure out how the output of the neural network would affect the loss value (then we can consider how to adjust the neural network parameters to affect its outputs).

## Back propagation of the gradient information

This is the core steps of the back-propagation algorithm for computing the gradient of the loss w.r.t. the neural network parameters, i.e. how the weights and the bias parameters of the perceptrons in each layer would affect the loss. The computation follows our previous discussion. In the video, the computer implementation is demonstrated.

## Unit Test of Back propagation 

BP is a complicated algorithm and is error-prone. In this video we demonstrate the straightforward idea of testing — we implement a numerical differentiation of how the network parameters affect the loss and compare the numerical differentiation and the gradient computed using BP.

## BP for the bias terms

We computer the gradient w.r.t. to the bias terms in each layer. The calculation is very similar to what we did for the weights.

## Optimisation

After obtaining the gradient of the loss function with respect to all the model parameters, we are ready to plan how to adjust those parameters in the next iteration step. The optimiser is to adjust the model parameters to follow the gradient direction by a small step to minimise the loss. This video shows a straightforward implementation of an optimiser.

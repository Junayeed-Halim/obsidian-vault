## The Challenge

Your task is to **write a program** that takes a 16-bit binary string (like the ones in the \(X\) column) as input and produces the correct corresponding 1-bit output (\(Y\)).

\[ f(X) \rightarrow Y \]

Look at the raw data above.

- Can you spot a pattern immediately?
- If you had to write a computer program function predict(x_bits) -> y_bit right now, what logic would you put inside it?

This is the essence of **Learning from Data**. We are not given the specifications (e.g., "calculate the velocity based on physics equations"). instead, we are given *observations* (outcomes), and we must reverse-engineer the *process* that generated them.

Before proceeding to the next page, please take a moment to think about the problem, and perhaps writing a Python program in the form of

def predict(x_bits):
 # your logic here, x_bits is a 16-bit binary string
 return y_bit

In the next page, we will try to "crack" this code manually, which will give us a concrete example of "from data to an executable program" -- the core task of learning from data.

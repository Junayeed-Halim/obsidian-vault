Tutorials

The following tutorials show the realisation of an Adaboost algorithm.

## One iteration step

In this video, we implement the Adaboost example that we went through "manually" using a Python program. It shows a single step of the algorithm, including resampling, training-evaluating-weighting the weak classifier, and reweighting the data samples for the next iteration step. It also shows how to prepare the data and set up the experiment, as well as introducing some Python and Numpy basic skills to be used.

## The Main Loop of Training Iterations

In this video, we implement the Adaboost training iterations by building the main loop of the algorithm. We will make use of the previously built iteration step, as well as take care of the data structures to represent and manage the model.

# Structured Outputs: Probability Distributions and Information Theory

In the previous section, we discussed regression problems with scalar outputs. However, in many learning tasks, the model's output is no longer a single real number, but rather an object with internal structure. This also includes cases where the target value seems to be simple, but it is more natural to "lift" the representation to have more natural measurements between those objects, such as in multi-class classification problems, where the direct comparison between two class labels is not well defined (e.g., how to measure the distance between class "A" and class "B", AND how the distance compares to that between class "A" and class "C"?). The most common choice in such situations is to adopt the principled approach of formulating our belief, knowledge, bias, etc. about the target and task using the language of probability.

Hence we are considering a *structured* output space of probability distributions. Using the multi-class classification problem as our running example, we treat the model output as the estimated probability that the current input instance belongs to each possible category. Consequently, the new problem we face is how to mathematically and rigorously compare the discrepancy between two probability distributions: the one predicted by the model, and the "target" distribution representing the true label.

## Cross-Entropy Loss for Multi-class Classification

Before diving into the motivation of the design and any further ado, here is a core take-away point: in practice, we predominantly utilize the Cross-Entropy Loss: Given the true probability distribution \(y\) and the model's predicted probability distribution \(f(x)\), the cross-entropy loss is defined as:

\[ L(y, f(x)) = -\sum_{i} y_i \log(f(x)_i) \]

Notice that in the formula, both \(y\) and \(f(x)\) are complex objects (vectors) consisting of multiple components, hence the summation over the index \(i\). In literature, there are also other naming conventions, e.g. using \(p\) and \(q\) to denote the true and predicted distributions, respectively, hence to preserve the symbol \(y\) for the simple label. Often, one must bear with either i) abusing letter \(y\) for both a symble ("A", "B", etc.) and a vector of their distribution (the true distribution is usually, one-hot, with one entry of 100% and others 0%) or ii) introducing extra symbols \(p\) and \(q\) to distinguish labels and distributions over the labels. You may also encounter symbols such as \(\hat y\), \(\tilde y\) for various significance, the names are not super important as long as you understand the underlying meaning and keep being consistent.

Back to our example, as mentioned above, in typical classification tasks, the true label is usually encoded as a one-hot vector, meaning the position corresponding to the true class is \(1\), and all others are \(0\). In this scenario, the summation formula simplifies to \(-\log(f(x)_c)\), where \(c\) is the index of the true class.

Intuitively, if the model's predicted probability for the true class \(f(x)_c\) approaches \(1\), the loss approaches \(0\); conversely, if the predicted probability approaches \(0\), the logarithmic function imposes a massive penalty tending towards infinity. This mechanism forces the model to produce predictions that allocate probability to the categories of the true label.

It is worth reflecting on two situations:

- Increasing the predicted probability for the true class from \(0.9\) to \(0.91\), vs
- Increasing the predicted probability for the true class from \(0.000001\) to \(0.010001\).

## Information-Theoretic Foundations

Although the intuitive explanation above is sufficient to guide engineering implementations, to profoundly understand why this specific mathematical form is chosen, we must introduce the fundamental concepts of Information Theory. The first is Shannon Entropy, which is a measure of the uncertainty of a random variable. For a discrete probability distribution \(P\), its information entropy is defined as \(H(P) = -\sum_{i} P_i \log P_i\). The higher the entropy, the more chaotic the system is, and the greater the amount of unpredictable information it contains.

Cross-entropy is actually composed of two parts. Mathematically, it can be proven that the cross-entropy between distribution \(P\) (the true distribution) and \(Q\) (the predicted distribution) is equal to the information entropy of \(P\), denoted as \(H(P)\), plus the Kullback-Leibler Divergence (KL Divergence) from \(P\) to \(Q\), denoted as \(D_{KL}(P||Q)\). The KL divergence strictly measures the extra information loss incurred when using distribution \(Q\) to approximate distribution \(P\). Because the true label distribution \(P\) is a fixed constant in a given training dataset, its information entropy \(H(P)\) is also a constant. Therefore, minimizing the cross-entropy is mathematically strictly equivalent to minimizing the KL divergence between the predicted distribution and the true distribution.

Furthermore, we can examine the classification problem from the perspective of Conditional Entropy and Mutual Information. Given the feature vector \(X\), the conditional entropy of the target variable \(Y\), denoted as \(H(Y|X)\), measures the remaining uncertainty of the target label after knowing the model's input. A perfect model should yield a conditional entropy of zero. Mutual information, defined as \(I(X;Y) = H(Y) - H(Y|X)\), quantifies the reduction in uncertainty of \(Y\) after observing \(X\). When we minimize the cross-entropy loss over a large number of samples via a neural network, we are essentially fitting the true conditional probability distribution \(P(Y|X)\). Theoretically, the optimized cross-entropy loss is exactly the conditional entropy \(H(Y|X)\), which implies that the essence of the entire learning process is to extract the maximum possible mutual information between the input features and the target labels.

# The Criterion as a Functional on Function Space

In the previous part of this module, we focused on the instance loss \(L: \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_{\ge 0}\), which measures the discrepancy between the model's output and the desired output at a single point \(x \in \mathcal{X}\). We now take a step back and review the big picture: the “Criterion” as a component in the learning system is to help us pick a good “worker” from our candidate set \(\mathcal{H}\).

Formally, we are looking for a function \(h \in \mathcal{H}\) that approximates some unknown true system \(f^*: \mathcal{X} \to \mathcal{Y}\). To select the best candidate from \(\mathcal{H}\), we need an objective that assigns a single real number to each \(h\) — a number that reflects how well \(h\) agrees with \(f^*\) *across the entire domain* \(\mathcal{X}\). An object that maps a function to a real number is called a functional. The learning criterion is therefore a functional on \(\mathcal{H}\).

Here we have a subtle but important question. The instance loss \(L\) accepts two elements of the output space \(\mathcal{Y}\). Given two functions \(h_1, h_2 \in \mathcal{H}\), \(L\) only tells us how to compare \(h_1(x)\) and \(h_2(x)\) at a *single point* \(x\), but by itself it does not tell us how to compare \(h_1\) and \(h_2\) as function objects working over the entire domain \(\mathcal{X} \mapsto \mathcal{Y}\). Put intuitively: *tasting and judging two dishes is not the same as comparing two chefs.*

## The Risk of a Hypothesis

The most natural way to measure how well \(h\) agrees with \(f^*\) globally is to integrate the instance loss over the entire input domain:

\[ E_{\text{all}}[h] \;:=\; \int_{\mathcal{X}} L\!\bigl(h(x),\, f^*(x)\bigr)\, dx. \]

At every point \(x \in \mathcal{X}\), we compare \(h(x)\) and \(f^*(x)\) — two elements of \(\mathcal{Y}\) — via the instance loss \(L\), exactly as discussed in the previous part of this module. The integral then aggregates all these pointwise comparisons into a single number. An intuitive picture of this integral is shown below.

Figure 1: The total risk \(E_{\text{all}}[h]\) integrates the pointwise instance loss over the entire input space \(\mathcal{X}\).

Unfortunately, this integral is only conceptually defined: it is *not computable*, because the true system's reaction to all points in the domain — \(f^*(x)\) for every \(x \in \mathcal{X}\) — is unknown. All one can do is to approximate this idealised criterion using a finite sample, i.e.\ the training dataset where we have observed \(f^*(x_i)\) for some \(x_i\)'s. The practical picture looks like this:

Figure 2: In practice, the integral is replaced by a sum over the training dataset \(D = \{(x_i, f^*(x_i))\}_{i=1}^N\).

Using the training dataset, we now have an instrument to measure how well a candidate \(h\) approximates the true system \(f^*\). However, the discussion so far has been on a one-dimensional toy task, while almost all real-world tasks involve processing many variables simultaneously.

For example, consider the image-related tasks discussed earlier: the input is a 2D array of pixels, and each pixel can have multiple channels (e.g.\ RGB). If we disregard the spatial arrangement of those values and consider only the number of variables, a “flattened” image is a vector in \[ \mathbb{R}^{\#\text{rows} \;\times\; \#\text{cols} \;\times\; \#\text{channels}}. \] This space can easily have tens of millions of dimensions for images taken by a modern smartphone.

Hence we need to consider learning in high-dimensional spaces, and the picture becomes intriguing:

- Unfortunately, the approximate-integration-by-sampling approach \(\bigl(\int\!\cdots\, dx \approx \frac{1}{N}\sum_{i=1}^{N} \cdots\bigr)\) seems to be fundamentally inefficient and infeasible when the input space has very high dimension.
- 

Fortunately, the \(\int \cdots\, dx\) in the above argument is **not** the target we are really interested in. All hope is not lost.

The Empire of high-dimensional intractability shall not defeat us. We have a better weapon: *finite samples drawn from the Force of probability*.

## Optimization

The key ideas are

i) To describe "what is the optimal situation" is usually very important, and the first step to design "how to get the optimal situation"

ii) "What is the optimal situation" is often in a "counterfactual" form of "I should NOT make any update, if I do, I would make the situation worse" -- mathematically, it is a critical point, where the changes of controllable parameters do NOT immediately change the objective.

iii) Compute gradients can be done using the chain rule.

iv) An analogy of gradient based optimisation is perceptron training, where you update w according to the evaluated (x,y) pair.

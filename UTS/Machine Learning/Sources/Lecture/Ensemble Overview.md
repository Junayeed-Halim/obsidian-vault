## Ensemble methods

In this module, you are introduced to the idea of putting multiple learned data models together to make a complex and more powerful model. This strategy seems to require a lot of data because more models need to be constructed. But surprisingly, we can reuse the same training dataset by generating random copies and build the constitute data using those copies, which apparently gives us "free lunch" information from the data.

The idea leads to the powerful ensemble family of data models. We will briefly introduce several ensemble methods. The focus will be on one of the most widely used data models, the Adaboost algorithm. We will have tutorials, in which you will perform the algorithm by hand and implement it by programming.

### **Topics you'll cover:**

- Ensemble methods
- Resampling (Bootstrapping)
- Bagging/Random forest
- Adaboost
